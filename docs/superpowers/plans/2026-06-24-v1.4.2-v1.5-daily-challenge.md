### Task 9 — Daily Challenge API endpoints

**Files to create:**
- `backend/app/Http/Controllers/Api/DailyChallengeController.php`
- `backend/app/Http/Resources/DailyChallengeResource.php`
- `backend/app/Http/Resources/DailyGuessResultResource.php`

**Route additions in `backend/routes/api.php` (inside `auth:sanctum` group):**
```php
Route::prefix('daily')->group(function () {
    Route::get('/today', [DailyChallengeController::class, 'today']);
    Route::post('/{dailyChallenge}/guess', [DailyChallengeController::class, 'guess']);
    Route::get('/{dailyChallenge}/result', [DailyChallengeController::class, 'result']);
    Route::get('/leaderboard/weekly', [DailyChallengeController::class, 'weeklyLeaderboard']);
    Route::get('/stats', [DailyChallengeController::class, 'stats']);
});
```

**GET /api/daily/today:**
- Find DailyChallenge where `challenge_date = today AND status = active`.
- If not found: `{ "has_daily": false, "reason": "no_daily_challenge" }`
- If found, check if user has already guessed:
  - Not guessed: return challenge data WITHOUT `ball_x_ratio`, `ball_y_ratio`, `reveal_image_url`
  - Already guessed: return with `"already_played": true` (no ball data in today response — user must call /result)
- Response shape:
  ```json
  {
    "has_daily": true,
    "already_played": false,
    "daily_challenge": {
      "id": 1,
      "challenge_date": "2026-06-24",
      "challenge": {
        "id": 3,
        "title": "Corner Kick",
        "difficulty": "easy",
        "hidden_image_url": "http://...",
        "category": { "id": 1, "name": "Corner Kicks", "slug": "corner-kicks" }
      }
    }
  }
  ```

**POST /api/daily/{dailyChallenge}/guess:**
- `dailyChallenge` must be `status = active`.
- Validate: `guess_x_ratio` and `guess_y_ratio` both 0..1.
- Check duplicate: 422 `{ "message": "You have already played today's challenge." }` if already guessed.
- Calculate score using `ScoreService`.
- Store in `daily_challenge_guesses`.
- Return result (including `ball_x_ratio`, `ball_y_ratio`, `reveal_image_url` if available):
  ```json
  {
    "data": {
      "id": 1,
      "score": 87,
      "distance": 0.052,
      "guess_x_ratio": 0.43,
      "guess_y_ratio": 0.72,
      "ball_x_ratio": 0.45,
      "ball_y_ratio": 0.71,
      "reveal_image_url": "http://..."
    }
  }
  ```

**GET /api/daily/{dailyChallenge}/result:**
- User must have guessed. 404 if no guess found.
- Return same shape as POST guess response.

**GET /api/daily/leaderboard/weekly:**
- Current week = Mon–Sun containing today (or Sun–Sat — use ISO week: Mon–Sun).
- Find all `daily_challenge_guesses` for `daily_challenges` with `challenge_date` in current week.
- Aggregate by user: `total_score`, `challenges_played`, `avg_score`.
- Rank by total_score DESC.
- Return:
  ```json
  {
    "data": [
      { "rank": 1, "user_id": 1, "username": "xander", "name": "Xander", "total_score": 250, "challenges_played": 3, "avg_score": 83.3, "is_current_user": true }
    ],
    "week_start": "2026-06-22",
    "week_end": "2026-06-28"
  }
  ```

**GET /api/daily/stats:**
- Return current user's daily stats (streak logic from Task 16):
  ```json
  {
    "current_streak": 3,
    "best_streak": 7,
    "total_played": 12,
    "average_score": 74.5,
    "best_score": 98,
    "weekly_rank": 2
  }
  ```

### Task 16 — Streak logic

**File to create:** `backend/app/Services/DailyStreakService.php`

**Logic:**
```
current_streak:
  1. Get all dates where user submitted a daily_challenge_guess, ordered DESC.
  2. If today has a guess, start from today and count consecutive days backward.
  3. If yesterday has a guess (but today doesn't yet), count from yesterday backward.
  4. If neither today nor yesterday has a guess, streak = 0.

best_streak:
  1. Walk all guess dates ordered ASC.
  2. Count max consecutive day run.
```

**Implementation approach:**
- `getStreakForUser(User $user): array` returns `['current' => N, 'best' => M]`
- Use Carbon for date comparison.
- No caching for MVP.

export const dailyApi = {
  today: () => apiClient.request<TodayResponse>('/daily/today'),

  stats: () => apiClient.request<DailyStats>('/daily/stats'),

**Known limitations to document:**
- Timezone: all date logic uses UTC (server time). Users in different timezones may see daily reset at unexpected hours.
- Daily challenge must be manually seeded/created via admin panel. No auto-scheduling.
