# BallPicker v1.8.4 Mobile UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Focused polish pass: Friends screen collapsible structure + search, friend-request badges, tab bar label fix, Recent XP moved to All Ranks, Pitch Green default theme, small Delete account link, integrated Home header.

**Architecture:** All mobile changes are React Native (Expo SDK 56, React Navigation bottom tabs). One tiny backend change: default `selected_theme` to `pitch_green` for newly created users via an Eloquent model default (no schema change, no data rewrite — existing users keep their stored value).

- Do not redesign screens; polish only. Keep clean-sports-app direction.
- Do not overwrite existing users' theme choices (server values stay untouched).
- Backend: production-safe, no `migrate:fresh`.
- Validation: `npx tsc --noEmit`, `npx expo export --platform web`, `php artisan test`.
